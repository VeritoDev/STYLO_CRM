# ✂️ Stylo - Sistema de Gestión Dinámica para Salones de Belleza

Stylo es una aplicación móvil nativa para Android enfocada en el sector B2B (Business-to-Business) y B2C. Está diseñada para optimizar la gestión de citas y la relación entre estilistas profesionales y sus clientes, dejando atrás métodos analógicos. 
Proyecto de Trabajo de Fin de Grado Superior en Desarrollo de Aplicaciones Multiplataforma.

---

## 🚀 Características Principales

* **Gestión de Agenda Global:** Calendario interactivo en tiempo real para reservar, modificar y cancelar citas.
* **Control de Acceso (RBAC):** Roles diferenciados para Estilista (administrador) y Cliente.
* **Ficha Técnica y Salud:** Repositorio de datos críticos asociados a cada cliente.
* **Integridad de Datos:** Algoritmo de borrado en cascada para mantener la base de datos limpia.
* **Experiencia Bilingüe:** Soporte nativo en Español e Inglés.

---

## 🚧 Próximas Implementaciones (Roadmap)

Actualmente, el proyecto sigue en evolución. Las funcionalidades pendientes de integrar son:

* **Persistencia offline:** Desarrollo en curso para asegurar la operatividad ante fallos de red.
* **Notificaciones push:** Sistema de alertas para recordar citas.
* **Configuración detallada:** Módulo para que el estilista implemente y configure sus propios servicios.
* **Chat integrado:** Canal de comunicación directa con el estilista desde el apartado de clientes.
* **Pasarela de pagos:** Integración para gestionar depósitos previos a la reserva.
* **Evolución del Control de Versiones:** Transición hacia un modelo completo de ramas de funcionalidad (`feature/`) para aislar nuevas características y facilitar el mantenimiento.

---

## 🛠️ Tecnologías Utilizadas

* **Entorno de Desarrollo:** Android Studio
* **Lenguaje:** Kotlin / XML
* **Arquitectura:** MVVM (Model-View-ViewModel)
* **Backend y Base de Datos:** Firebase (Auth y Realtime Database NoSQL)
